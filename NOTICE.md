# Attribution and source

This project is a Python port of the Geomorphic Instream Flow Tool (GIFT)
developed by Stefan Gronsdahl.

Source repository: <https://github.com/SGronsdahl/GIFT>

Source revision used for this port:
`40c4a74f82d842cd2ab8ab4c53e2b985ac4e0030`

The port reproduces the computational behavior of:

- `R/AvgHydraulics.R`
- `R/Habitat.R`

The Ptolemy example suitability-curve CSV files are copied from the source
repository. The original README distributes GIFT under GNU GPL version 3 or
later. This derivative port uses the same license.

The Streamlit application adds the EROM-network display, COMID joins, monthly
habitat aggregation, custom-curve controls, comparisons, and Python plotting.
The original GIFT computational functions remain in `model/gift_habitat`.
The application calls these Python functions directly; it does not include the
previous static viewer's JavaScript translation of the habitat equations.

The reference suite in `tests/r_reference` includes unmodified copies of the
two original R source files, with frozen results generated by executing those
functions using their actual R dependencies. Its optional generator exposes
native hydraulic levels by changing only a copied function's return expression.
The source equations remain unchanged. Shape factors are used without capping.
The app's monthly aggregation and D84 substrate proxy remain documented extensions.
