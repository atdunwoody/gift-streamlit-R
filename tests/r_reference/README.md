# R-derived GIFT reference calculations

These frozen CSVs are generated by executing Stefan Gronsdahl's original R
functions at revision `40c4a74f82d842cd2ab8ab4c53e2b985ac4e0030`.
The unmodified source files are in `source/`, under the project's GPL-3.0-or-later
license. `provenance.json` records the R and dependency versions;
`source_hashes.csv` records source and suitability-curve MD5 hashes.

`generate_reference.R` runs the original functions with plotting disabled.
For native levels, it changes only the copied function's final return expression
to expose the already-calculated `simulated` table. The hydraulic and habitat
equations are unchanged. The actual dplyr, zoo, and birk packages are loaded.
No Python calculations supply the expected results.

The cases include the default width/depth shape estimate, maximum-depth inputs,
an explicit override, shape factors of 0, 0.7, 0.75, 0.85, and 0.99, and 11 reaches
from the supplied network. Factors above 0.7 are retained. The R source prints a
caught error for these factors, then continues; this is expected when generating
the references. The Python model rejects factors outside [0, 1).

The habitat references cover all six supplied curve sets with no substrate input,
a ten-grain distribution, and a single-size D84 proxy. Monthly references also
exercise the app's documented extension: interpolate native R hydraulics at each
exact monthly flow, evaluate habitat separately, and apply the D84 proxy. The
zero-flow and availability rules belong to the application, rather than the
original R Habitat function.

Python tests use a relative tolerance of 2e-9 and absolute tolerance of 2e-11 for
hydraulic comparisons, allowing floating-point summation differences between R
and NumPy. Habitat at identical hydraulic inputs uses 2e-12 absolute tolerance.
These limits are much smaller than the earlier wet/dry-grid discrepancies.

Normal verification requires only `pytest`; R is optional. To regenerate the
fixtures, install R plus `dplyr`, `zoo`, and `birk`, then source
`tests/r_reference/generate_reference.R` in VSCode's R session. Run the Python
test suite after regeneration.

The monthly-reference tests reconstruct hydraulic inputs from the frozen
`hydraulic_cases.csv` and `monthly_inputs.csv`. They do not substitute the
current app GeoPackage, whose geometry may have been updated after the R
references were generated. The application's active source joins and rebuilds
are checked separately in `test_habitat.py` and `test_data_preparation.py`.
